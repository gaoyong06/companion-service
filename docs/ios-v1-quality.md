# iOS V1 产品质量标准与检查清单

> 目标：她记得你，而且不会打扰你。  
> 适用范围：Companion iOS 首发版本  
> 文档状态：Release Baseline  
> 更新日期：2026-08-09

## 1. 核心定义

“记得你”不是把用户说过的每句话都写入长期记忆，而是建立可验证的数据契约：

| 内容类型 | 处理方式 | V1 量化要求 |
| --- | --- | --- |
| 原始文本、语音转写、图片/视频资产引用 | 保存到连续时间线 | 接受成功的消息持久化成功率 100%；失败必须明确返回错误，不允许静默丢失 |
| 稳定偏好、重要事实、进行中的目标 | 进入候选记忆并按策略召回 | 评测集中的有效记忆召回率 >= 90%，有效记忆准确率 >= 95% |
| 一次性情绪、闲聊细节、短期状态 | 保留在上下文，不自动成为长期记忆 | 误写入率 <= 5% |
| 密码、令牌、证件、银行卡、精确住址等敏感内容 | 默认不写入长期记忆 | 敏感信息长期记忆泄漏率 = 0 |
| 用户明确说“不要记住”或“不保存” | 当前内容不进入长期记忆，也不参与后续召回 | 后续召回残留率 = 0 |

因此，“记住所有事情”在产品上被拆成两条可验收承诺：**对话不丢失**，以及**重要且被允许的事情可以被正确记住**。不把敏感或短期内容全部记下来，才是可信的记忆。

“不会打扰你”的 V1 定义更加严格：首发版本不发送未经用户明确授权的主动消息，不以通知、签到、连续任务或情感话术制造回访压力。

## 2. 发布硬门槛

以下任意一项不达标，禁止提交 App Store 审核：

| 类别 | 指标 | 计算方式 | V1 门槛 |
| --- | --- | --- | --- |
| 数据完整性 | 消息持久化成功率 | 成功响应对应的消息写入数 / 已接受消息数 | 100% |
| 记忆准确性 | 有效记忆准确率 | 标注为有效的长期记忆 / 抽取的长期记忆 | >= 95% |
| 记忆覆盖 | 有效记忆召回率 | 被标注为应记住且在规定窗口内成功召回的记忆 / 应记住记忆总数 | >= 90% |
| 召回相关性 | 不相关记忆误召回率 | 被注入上下文但与当前问题无关的记忆 / 注入记忆总数 | <= 5% |
| 记忆纠错 | 纠错后再次错误率 | 用户纠正后再次输出旧事实的次数 / 纠错事实的召回次数 | <= 1% |
| 用户禁记忆 | 禁记忆残留召回率 | 明确拒绝保存后仍被召回的次数 / 禁记忆样本数 | 0 |
| 隐私安全 | 敏感信息长期记忆泄漏率 | 敏感样本进入长期记忆或被召回的次数 / 敏感样本数 | 0 |
| 破冰流程 | 阶段状态正确率 | 服务端状态与预期状态一致的请求数 / 评测请求总数 | 100% |
| 破冰体验 | 用户可见的强制会话操作 | 新建、选择、关闭会话等强制操作次数 | 0 |
| 打扰控制 | 未授权主动消息数 | 未开启授权时发送的主动消息数 | 0 |
| 安全 | 高风险样本漏处理率 | 未进入安全策略的高风险样本 / 高风险样本总数 | 0 |
| 稳定性 | Crash-free session | 无崩溃会话 / 总会话 | >= 99.5% |

## 3. 性能目标

性能不是“感觉快”，统一使用 P50/P95 统计：

| 指标 | P50 目标 | P95 目标 |
| --- | ---: | ---: |
| iOS 冷启动到可输入 | <= 1.5s | <= 2.5s |
| 文本首 token | <= 1.0s | <= 2.0s |
| 记忆召回 | <= 120ms | <= 300ms |
| 记忆异步处理完成 | <= 10s | <= 30s |
| 语音开始播放 | <= 1.8s | <= 3.0s |
| 明确“不要记住”后的同步生效 | <= 500ms | <= 2.0s |

记忆召回超过 300ms 时允许跳过本轮召回，不得阻塞用户继续聊天；模型供应商延迟单独统计，不能用模型等待掩盖服务端性能。

## 4. 评测集与评分方法

V1 发布前建立至少 500 个带期望结果的对话场景，每个场景由两名标注人员独立判断；关键标签一致性 Cohen's Kappa >= 0.80。

场景配比如下：

| 场景 | 最低数量 | 核心检查 |
| --- | ---: | --- |
| 稳定偏好、事实、目标 | 120 | 是否正确抽取和未来召回 |
| 时间变化和事实更新 | 60 | 是否使用新事实，避免旧事实覆盖 |
| 用户纠错和“忘掉这件事” | 60 | 删除传播和再次召回 |
| “不要记住”与会话级禁记忆 | 60 | 0 残留召回 |
| 敏感信息和安全风险 | 80 | 0 长期保存、危机策略正确 |
| 无关历史干扰 | 50 | 不相关记忆不进入 Prompt |
| 中英文及 Accept-Language | 40 | locale 选择和安全回退 |
| 文本、语音、图片、视频 | 30 | 多模态共用连续关系和记忆边界 |

每个记忆断言使用统一标签：

- `KEEP`：应进入长期记忆。
- `CONTEXT_ONLY`：只能保留在短期上下文。
- `DO_NOT_STORE`：不得写入长期记忆。
- `RECALL`：当前问题应召回。
- `DO_NOT_RECALL`：当前问题不应召回。

每个样本至少检查：抽取结果、存储结果、召回结果、最终 Prompt、用户可见回复和审计事件。只看最终回答相似度，不算通过。

## 5. iOS 首发验收清单

### 5.1 核心体验

- [ ] 首次打开直接进入聊天，不要求填写长问卷。
- [ ] Companion 有固定名字和稳定身份，首次对话完成自然破冰。
- [ ] 用户可以直接发送下一条消息，不需要新建或选择会话。
- [ ] 文本、语音、图片和视频进入同一条连续时间线。
- [ ] 用户返回 App 后可以继续上次的关系上下文。
- [ ] 默认回复 1 到 3 句，一次最多一个问题，有自然停顿。
- [ ] 模型失败时明确反馈，不伪造已记住或已完成的状态。

### 5.2 记忆体验

- [ ] 稳定偏好、重要事实和目标可以被正确记住。
- [ ] 一次性情绪和闲聊细节不会大量进入长期记忆。
- [ ] 用户说“不要记住”后，内容不再进入长期记忆和后续召回。
- [ ] 用户说“忘掉这件事”后，相关记忆、向量和缓存均不再召回。
- [ ] 用户纠正事实后，新事实优先，旧事实不会继续主导回复。
- [ ] 系统不会向用户展示内部 `L1/L2/R`、Embedding 或 `onboarding_stage` 等术语。

### 5.3 不打扰

- [ ] V1 默认不发送主动消息。
- [ ] V1 默认不请求通知权限，只有用户主动开启提醒时才请求。
- [ ] 没有签到、连续天数、未读红点诱导和“我想你了”式压力文案。
- [ ] 未来主动联系必须有授权、静默时间、每日上限和一键暂停。
- [ ] 用户关闭主动联系后，2 秒内停止新的计划任务和通知。

### 5.4 Apple 审核与隐私

- [ ] 不提供露骨色情内容、未成年人恋爱内容或情感控制话术。
- [ ] 不把 AI 描述为真实人类，不声称拥有现实经历或身体。
- [ ] 危机内容提供本地化安全转介，不声称替代专业机构。
- [ ] 隐私说明与实际的消息、音频、媒体、记忆存储链路一致。
- [ ] 不在日志中记录完整用户输入、完整模型回复、原始音频地址或供应商密钥。

## 6. 上线后观察指标

以下指标用于产品迭代，不作为首发前的唯一通过条件：

| 指标 | 定义 | 首月观察目标 |
| --- | --- | ---: |
| 首次有效对话完成率 | 完成至少 4 轮自然交流的首日用户 / 首次打开用户 | >= 60% |
| 72 小时连续关系回访率 | 72 小时内再次发送消息的用户 / 首次有效对话用户 | >= 30% |
| 用户重复解释率 | 用户明确重复同一事实的会话 / 有相关历史的会话 | <= 10% |
| 用户纠错率 | 纠正记忆的用户数 / 使用长期记忆用户数 | 先观察，不设“越低越好” |
| 记忆相关投诉率 | 与错误记忆、隐私或遗忘有关的投诉 / 月活用户 | <= 1% |
| 主动打扰投诉率 | 主动消息相关投诉 / 主动消息接收用户 | V1 为 0；授权功能上线后 <= 1% |

留存、付费率和日活不能替代记忆准确性。若留存上升但错误记忆、隐私投诉或主动打扰同时上升，判定为产品质量下降。

## 7. Go / No-Go 规则

### Go

- 所有发布硬门槛达标。
- 500 个评测场景完成，关键标签一致性达标。
- iOS 真机完成文本、语音、后台恢复、弱网和权限拒绝测试。
- 数据库、RocketMQ、asset-service、model-gateway 的失败路径有可观测记录。

### No-Go

出现以下任意情况必须延期：

- 任何敏感信息或明确禁记忆内容进入长期记忆。
- 用户纠错或遗忘后仍能召回旧内容。
- 未授权主动发送消息或通知。
- 用户消息或 assistant 回复静默丢失。
- 首次破冰依赖用户手动管理会话。
- 为了提高留存加入强制签到、情感施压或低俗内容。

## 8. 每周质量复盘

每周固定输出一份质量报告，至少包含：

1. 记忆准确率、召回率、误召回率和禁记忆残留率。
2. 用户纠错、遗忘、隐私和主动打扰投诉样本。
3. P50/P95 延迟、错误率、崩溃率和消息持久化成功率。
4. 新增失败样本及其回归测试编号。
5. 本周允许修改的 Prompt/策略词条、版本号、影响语言和回滚状态。
